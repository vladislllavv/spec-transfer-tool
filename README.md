# spec-transfer-tool

Веб-приложение для автоматического переноса данных из расчётной Excel-таблицы
сразу в два готовых шаблона. Оба шаблона зашиты в приложение — пользователь
загружает только свой файл, а два готовых файла скачиваются автоматически.

## Что переносится

По каждой строке исходного файла — название товара, характеристики, область
применения, торговая марка, артикул, количество, вес брутто, цена за
единицу, сумма, объём, а также фотография товара (если она встроена в
исходный файл, в колонке "Фото товара"), в исходном пиксельном разрешении.

Столбцы шаблона, для которых нет соответствующих данных в источнике,
остаются пустыми — никаких выдуманных значений.

## Два выходных файла

| Файл | Шаблон | Профиль |
|---|---|---|
| `Приоритет.xlsx` | `data/template.xlsx` | `SPECIFICATION_PROFILE` |
| `Битрикс.xlsx` | `data/bitrix-template.xlsx` | `BITRIX_PROFILE` |

При загрузке файла на сайте оба запроса (`POST /api/transfer?target=priority`
и `POST /api/transfer?target=bitrix`) уходят параллельно, и оба файла
скачиваются один за другим.

Соответствие колонок для каждого профиля задано в `src/lib/transfer.ts`.

## Запуск локально

```bash
npm install
npm run dev
```

Откройте [http://localhost:3000](http://localhost:3000), загрузите `.xlsx`
файл — оба готовых файла скачаются автоматически.

## Как это устроено

- `src/lib/transfer.ts` — вся логика переноса: поиск строки заголовков по
  маркерному тексту (устойчиво к смещению заголовков), перенос значений по
  `columnMapping` профиля, перенос встроенных изображений с сохранением
  исходного разрешения, очистка демонстрационных строк/фото шаблона.
  Экспортирует `SPECIFICATION_PROFILE`, `BITRIX_PROFILE` и общую функцию
  `transferToTemplate(buffer, profile)`.
- `src/app/api/transfer/route.ts` — API-роут (`POST /api/transfer?target=<id>`),
  принимает `multipart/form-data` с полем `file`, `target` — `priority` или
  `bitrix`, возвращает готовый `.xlsx`.
- `src/app/page.tsx` — страница загрузки файла (drag-n-drop или выбор файла),
  параллельно запрашивает оба целевых файла и скачивает их в браузере.
- `data/template.xlsx`, `data/bitrix-template.xlsx` — шаблоны, встроенные в
  приложение.

## Деплой на Vercel

```bash
vercel --prod
```

Специальная конфигурация не требуется — обработка идёт в обычной Node.js
serverless-функции (`export const runtime = "nodejs"` в API-роуте).

_Автодеплой подключён: пуш в main -> продакшн на Vercel._
