# spec-transfer-tool

Веб-приложение для автоматического переноса данных из расчётной Excel-таблицы
в спецификацию. Шаблон спецификации зашит в приложение (`data/template.xlsx`) —
пользователь загружает только свой файл, а готовая спецификация сразу
скачивается.

## Что переносится

По каждой строке исходного файла:

- название товара, технические характеристики, область применения;
- торговая марка, артикул, количество, вес брутто;
- цена за единицу, сумма, объём;
- фотография товара (если она встроена в исходный файл, в колонке "Фото
  товара"), в исходном пиксельном разрешении.

Столбцы шаблона, для которых нет соответствующих данных в источнике
(производитель, страна происхождения, модель, ссылка, вес нетто/шт., вес
брутто/шт.), остаются пустыми — никаких выдуманных значений.

Соответствие колонок задано в `src/lib/transfer.ts` (`COLUMN_MAPPING`).

## Запуск локально

```bash
npm install
npm run dev
```

Откройте [http://localhost:3000](http://localhost:3000), загрузите `.xlsx`
файл — готовая спецификация скачается автоматически.

## Как это устроено

- `src/lib/transfer.ts` — вся логика переноса: поиск строки заголовков по
  маркерному тексту (устойчиво к смещению заголовков), перенос значений по
  `COLUMN_MAPPING`, перенос встроенных изображений с сохранением исходного
  разрешения, очистка демонстрационных строк/фото шаблона.
- `src/app/api/transfer/route.ts` — API-роут (`POST /api/transfer`), принимает
  `multipart/form-data` с полем `file`, возвращает готовый `.xlsx`.
- `src/app/page.tsx` — простая страница загрузки файла (drag-n-drop или выбор
  файла), скачивание результата в браузере.
- `data/template.xlsx` — шаблон спецификации, встроенный в приложение.

## Деплой на Vercel

```bash
vercel --prod
```

Специальная конфигурация не требуется — обработка идёт в обычной Node.js
serverless-функции (`export const runtime = "nodejs"` в API-роуте).
